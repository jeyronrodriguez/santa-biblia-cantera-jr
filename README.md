# Santa Biblia Cantera JR

Starter Flutter multiplataforma para Android e iOS.

## Requisitos
- Flutter SDK estable
- Android Studio (Android)
- Xcode en macOS (iOS)

## Ejecutar
```bash
flutter pub get
flutter run
```

## Estado
Esta es una primera base de interfaz y navegación. Todavía no es una app lista para publicar.
El texto de Cantera-Iglesias no está incluido. Antes de distribuirlo hay que obtener licencia escrita
que cubra reproducción digital, distribución móvil, uso sin conexión y territorios de publicación.

## Próximos pasos
1. Confirmar con BAC/titular de derechos la licencia digital.
2. Incorporar texto autorizado y metadatos exactos de libros/capítulos/versículos.
3. Implementar búsqueda real, favoritos, notas y almacenamiento local.
4. Añadir pruebas, accesibilidad, política de privacidad y ficha de tiendas.
5. Generar y probar builds Android/iOS; la publicación requiere cuentas de desarrollador.
