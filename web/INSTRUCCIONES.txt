# Santa Biblia Cantera JR — archivos PWA

Estos archivos complementan la carpeta `web/` de Flutter. No reemplazan `web/index.html` ni `web/flutter_bootstrap.js`.

## 1. Copiar archivos
Sube `manifest.json`, `service-worker.js` y la carpeta `icons/` dentro de `web/` en el repositorio.

## 2. Editar `web/index.html`
Dentro de `<head>`, agrega:
```html
<link rel="manifest" href="manifest.json">
<link rel="apple-touch-icon" href="icons/apple-touch-icon.png">
<meta name="theme-color" content="#0d362a">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<meta name="apple-mobile-web-app-title" content="Santa Biblia Cantera JR">
```
Antes de `</body>`, agrega:
```html
<script>
  if ('serviceWorker' in navigator) {
    window.addEventListener('load', () => {
      navigator.serviceWorker.register('service-worker.js');
    });
  }
</script>
```
Conserva todo el código Flutter que ya exista en `index.html`, especialmente el bootstrap de Flutter.

## 3. Compilar y publicar
La compilación web debe ejecutar:
```bash
flutter pub get
flutter build web --release --base-href "/santa-biblia-cantera-jr/"
```
Luego publica el contenido de `build/web/` en GitHub Pages. El `base-href` debe coincidir con el nombre del repositorio.

## 4. Instalar en iPhone
Cuando GitHub Pages esté publicado por HTTPS, abre la dirección del sitio en Safari, pulsa Compartir → Añadir a pantalla de inicio → Añadir.

## Importante
- Estos archivos no contienen el texto Cantera-Iglesias.
- El service worker guarda el shell y recursos solicitados después de conectarse; no garantiza que todo el contenido de la Biblia funcione sin conexión. Eso requiere implementar y probar almacenamiento local en la app.
- No reemplaces `web/index.html` completo con una plantilla nueva; conserva el bootstrap de Flutter.
